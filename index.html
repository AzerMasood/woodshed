Set up the helper (once)

The helper is one small file that runs on your PC. It fetches the audio from the link with yt-dlp and splits the song on your graphics card.

1. Install Python from python.org if you do not have it (tick Add to PATH).

2. In a terminal run: pip install -U yt-dlp numpy onnxruntime-directml

3. Save woodshed-helper.py anywhere and run: python woodshed-helper.py

4. Leave that window open while you use Woodshed. If the browser asks to allow access to devices on your local network, choose Allow.

If yt-dlp complains about a JavaScript runtime for YouTube, install Deno too. YouTube often asks yt-dlp to prove it is not a bot. If so, start the helper with python woodshed-helper.py --cookies-from-browser firefox after logging in to YouTube in Firefox. The same option helps for Instagram. Chrome and Edge cookies often fail on Windows, so Firefox is the reliable choice.

Fret pad

Open a tab, select its text, copy it (Ctrl+C), then press Paste tab from clipboard. If this area stays blank, the site refuses to be shown inside another page, so use Open in new tab.

Click a cell and type a fret number (arrow keys move, Backspace clears, | toggles a bar line, Space plays). Drag across the thin strip above the columns to select a section, then mark it learned. A single click on a strip toggles one column.
